# Skill: Code Cleanup & Deobfuscation

## Goal
Transform raw, obfuscated, or decompiled code into readable, well-structured, and idiomatic representations.

## Rules
1. Identify cryptic variable and argument names (e.g., `local_10`, `param_1`, `a`, `b`) and suggest semantic renamings based on usage.
2. Group related operations into conceptual blocks and document parameter constraints.
3. Simplify convoluted branching and dead code branches resulting from decompilation heuristics.
4. Extract structured interfaces and types for complex struct pointers.
