# Skill: Repository Onboarding & Architecture Discovery

## Goal
Rapidly comprehend, map, and document a software codebase architecture, dependencies, module boundaries, and execution flow.

## Rules
1. Map the top-level directory structure and identify primary entry points (e.g. `main()`, `index.ts`, `app.py`).
2. Discover core abstractions, data models, and service interfaces.
3. Trace the primary runtime execution paths and inter-module communications.
4. Highlight external system dependencies (databases, APIs, MCP servers).
5. Produce a high-level component interaction diagram using Mermaid flowchart notation.
