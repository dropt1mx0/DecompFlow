# Skill: Web Application API & Client Routing Mapper

## Goal
Map and document client-side routing, DOM components, REST/GraphQL endpoints, and WebSocket channels for web applications.

## Rules
1. Extract client bundle assets, scripts, and stylesheet links from target DOM via Playwright MCP.
2. Intercept and document outgoing XHR/Fetch API endpoints and WebSocket channels.
3. Map frontend route definitions and authentication session handlers (`/api/v1/auth`, cookies, tokens).
4. Evaluate client-side input validation and Content Security Policy (CSP) headers.
5. Generate an endpoint interaction flow diagram using Mermaid sequence notation.
