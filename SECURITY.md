# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of DecompFlow and the safety of our users seriously.

If you believe you have discovered a security vulnerability in DecompFlow (including core workflow execution, MCP communication bridges, or desktop renderer IPC boundaries), please do not open a public issue.

Instead, please report it privately:
- Through [GitHub Private Vulnerability Reporting](https://github.com/dropt1mx0/DecompFlow/security/advisories/new)
- Or by email to `dropt1m.sup@gmail.com`

Please include:
- A description of the vulnerability and potential impact.
- Step-by-step instructions or minimal proof-of-concept to reproduce the behavior.
- Affected components (CLI, Core graph, or Desktop).

We will acknowledge receipt within 48 hours and coordinate a fix and advisory disclosure.
